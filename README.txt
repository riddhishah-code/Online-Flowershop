BLOOM BASKET - ONLINE FLOWER SHOP
================================

Technologies:
- Core PHP
- MySQL
- HTML
- CSS
- Small amount of JavaScript only for confirmation

SETUP USING XAMPP
-----------------
1. Install and start Apache + MySQL in XAMPP.
2. Copy the "flower-shop" folder into:
   C:\xampp\htdocs\
3. Open phpMyAdmin:
   http://localhost/phpmyadmin
4. Import "flower_shop.sql".
5. Open:
   http://localhost/flower-shop/

IMPORTANT
---------
The project is intentionally kept beginner-friendly for a bachelor project.
The flower images are loaded from public image URLs, so internet access is needed
to display the demo images. You can replace the URLs with local images later.

PROJECT FEATURES
----------------
Customer:
- Register/Login
- Browse flowers
- Flower details
- Session cart
- Checkout
- View orders

Admin:
- Admin login
- Dashboard
- Add/Edit/Delete flowers
- Manage stock
- Manage customer orders
- Change order status

NOTE
----
The demo SQL contains sample products and users so the project does not look empty
after importing the database.
